# Elan Skin — Skincare Treatments Showcase / Portfolio Gallery

A multi-page luxury editorial skincare website based on the uploaded design direction: dermatologist gallery + luxury editorial + treatment archive. It uses Audiowide for all text.

Pages: Home, Treatments, Treatment Detail, Results, Specialists, About (Philosophy), Consultation.

Open index.html. Most images are remote Unsplash URLs, so internet access is required for those; a few are stored in the `images` folder. The logo and favicon are in `logo.png`.
